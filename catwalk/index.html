How to play

Lay a single connected trail of cat paws 🐾 from the entry nub to the exit nub.

The trail never branches, never crosses, and never loops — each paw connects to exactly two neighbours.

The number beside each row and above each column is how many paws it holds.

Tap a cell to cycle: ✕ (no track), then the six paw-track pieces — straights and elbows — then clear. Orient each piece so the paws link into one unbroken trail. Tap a row/column number to ✕ the rest of that line.
